# GitHub issue template (one issue per approved PR request)

Title: `tests: <short group name>` (for example `tests: remove redundant checkout e2e tests`)

Body:

```markdown
## Goal
<One or two sentences: what this change achieves for the test suite.>

## Items
- [ ] <Action> `<test or file>`: <reason with evidence> (impact <n>, effort <S/M/L>)
- [ ] ...

## Expected effect
- Tests: <before> -> <after>
- Runtime: <estimated change>
- Coverage: <must not drop in: files/areas>

## How to verify
1. Run `<test command>` and confirm it passes.
2. Run `<coverage command>` and compare against the baseline in `.agents/knowledge/testing.md`.
3. <Any group-specific check, e.g. confirm behavior X is still covered by <test>.>

## Notes
Generated by the review-tests skill on <date> at <commit>. Order: <this is PR n of m; depends on ... or independent>.
```

Labels: `tests` plus `tech-debt` (use only labels that already exist in the repo; do not create labels).
